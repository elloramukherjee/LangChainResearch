# LangChainResearch

An exploration of [LangChain](https://www.langchain.com/) for building agentic AI applications, centered around an **Agentic AI Research Assistant** — an agent that can search, reason over, and summarize information to help with research tasks.

## Project Structure

```
LangChainResearch/
└── Agentic_AI_Research_Assistant/   # Core agent implementation
```

## Goals

- Learn and experiment with LangChain's core abstractions (chains, agents, tools, memory, retrievers)
- Build an agentic research assistant capable of multi-step reasoning and tool use
- Document findings and patterns as the project evolves

## Getting Started

